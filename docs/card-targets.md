# カード効果の対象定義

効果の `target` に対象種別と選択数を指定します。対象の選択はコスト支払いより前に行われ、選択中はカード使用処理が保留されます。

```json
{
  "target": {
    "type": "TARGET_CARD",
    "amount": 1,
    "filter": {
      "zones": ["FIELD"],
      "controller": "OPPONENT",
      "cardTypes": ["ITEM"],
      "faceUp": true,
      "tags": ["POTION"]
    }
  }
}
```

## 対象種別

| type | 処理 |
|---|---|
| `NONE` | 対象を取らない。 |
| `SELF` | 使用プレイヤーを自動的に対象にする。 |
| `PLAYER` | 全プレイヤーから選ぶ。 |
| `OPPONENT` | 使用者以外のプレイヤーから選ぶ。 |
| `ALL_PLAYERS` | 全プレイヤーを自動的に対象にする。 |
| `SELF_CARD` | 効果の発生源カードを自動的に対象にする。 |
| `TARGET_CARD` | 条件に合うカードから選ぶ。ゾーン未指定時は場を参照する。 |
| `ALL_CARDS` | 条件に合う全カードを自動的に対象にする。 |
| `HAND` | 使用者の手札から選ぶ。 |
| `DECK` | 使用者のデッキから選ぶ。 |
| `DISCARD` | 墓地のカードから選ぶ。 |

`amount` は選ぶ件数で、省略時は1件です。現在は最小数と最大数が同じ固定数選択です。

## カードフィルター

- `zones`: 対象にできるゾーン。
- `controller`: `SELF`、`OPPONENT`、`ANY`。
- `cardTypes`: 対象にできるカード種別。
- `faceUp`: 表向き・裏向きの指定。
- `tags`: すべて持っている必要があるカードタグ。

相手の手札、デッキ、リソース、冒険者デッキは候補情報を公開しません。現時点でプレイヤー対象に対応する実行コマンドは `DRAW`、`LOSE_MP`、`HEAL`、`ADD_QUEST_MODIFIER` です。カード自体を移動・破棄するコマンドは今後の効果種類拡充で実装します。
